# Niamey-Manure-Sellers-Analysis

## Description
This data analysis project focuses specifically on the distribution link of the agricultural supply chain: **manure sellers** operating within the cattle markets of Niamey. Extracted from a comprehensive Master 2 thesis evaluating manure quality and its valorization chain, this repository explores the sourcing, storage, and resale dynamics managed by these key intermediary actors.

## Research Objectives
The project aims to decode the economic and logistical role of sellers within the value chain by addressing the following key questions:
* **Collection & Storage Practices:** How do management conditions implemented by sellers affect the final quality and degradation of the product before resale?
* **Market Dynamics:** What are the transactional flows connecting livestock owners (suppliers) to urban and peri-urban farmers (end consumers) through these intermediaries?
* **Losses & Inefficiencies:** Where do material and nutrient (N, P, K) losses occur within this specific segment of the chain?

## Technical Stack
* **Data Cleaning & Exploration:** Python (Pandas, NumPy)
* **Data Visualization:** Python (Matplotlib, Seaborn) for analyzing seller profiles and volume distributions.
* **Data Structuring:** SQL for relational modeling of transaction flows.

## Repository Structure
* `/data` : Cleaned and anonymized survey datasets (volumes, manure storage types, transaction prices).
* `/notebooks` : Interactive Jupyter Notebooks detailing the Exploratory Data Analysis (EDA) and statistical processing.
* **To view the charts for this project, please consult the `vendeur.ipynb` notebook.**
* `/visualizations` : Charts illustrating vendor distributions, storage durations, and buyer typologies.
* `/docs` : Summary of key performance indicators (KPIs) and core operational insights.
